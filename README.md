# HH Goa 2026-Builder ID Generator

A fast, browser-based Builder ID generator inspired by the visual identity of Hacker House Goa 2026.

Upload a photo, enter your name, role, and tech stack, and generate a personalized HH Goa-style Builder ID poster.

##  Live Demo

https://hh-goa-builder-id-lake.vercel.app/

##  Features

- Upload your own photo
- Generate a unique Builder ID
- Personalized name, role and tech stack
- Dynamic Builder Class
- HH Goa-inspired visual design
- 1080 × 1350 poster output
- Download the generated poster as PNG
- Runs entirely in the browser
- No login required
- No API key required
- No database required

##  Tech Stack

- Next.js
- React
- TypeScript
- CSS
- HTML Canvas

No API key, login, database, or external image service is required. Rendering and PNG export happen in the browser.
